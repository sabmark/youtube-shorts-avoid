# Shorts Avoid for YouTube v0.1.30

The Avoid and Like buttons work again on the latest YouTube layout.

Changes since v0.1.29:

- **Avoid and Like show up again.** For signed-in viewers, YouTube changed how it builds the Shorts player, and the extension no longer found it. The buttons simply did not appear. The extension now recognizes both the old and the new player.
- **The buttons sit just above the channel avatar.** Avoid and Like now come right before the round channel avatar at the bottom of the Shorts actions, instead of after it.

## Install or update

Install [Shorts Avoid for YouTube from the Chrome Web Store](https://chromewebstore.google.com/detail/shorts-avoid-for-youtube/capdpopadgbflaoklceadlimohpcmopm). Store installations update automatically once the store approves v0.1.30.

For manual installation, download `youtube-shorts-avoid-0.1.30.zip` and extract it to a permanent folder. Open `chrome://extensions` or `opera://extensions`, enable Developer mode, select **Load unpacked**, and choose the extracted folder containing `manifest.json`.

For an unpacked update, replace the files in the existing extension folder, reload the extension, and reload YouTube. Use a signed-in account with YouTube set to English. `SHA256SUMS.txt` contains the ZIP checksum.

## Verification

All 127 automated tests passed with zero failures. On November 26, 2026 the owner loaded the fixed build in their signed-in Chrome and confirmed that Avoid and Like appear above the channel avatar and work. The placement was also checked on signed-out live YouTube Shorts.
