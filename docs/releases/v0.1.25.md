# Shorts Avoid for YouTube v0.1.25

Choose which feedback Avoid sends: **Not interested**, **Don't recommend channel**, or **Both (default)**. The saved choice applies to the Avoid button and its shortcut, including Left Arrow, and updates open Shorts tabs.

Changes since v0.1.22:

- Like and move to the next Short immediately with the heart button or Like shortcut. An existing like stays selected.
- Use the new Shorts Avoid for YouTube name and minus-and-heart logo.
- Select video feedback, channel feedback or both in Options. Avoid waits until the saved choice is known before enabling.

## Install or update

Install [Shorts Avoid for YouTube from the Chrome Web Store](https://chromewebstore.google.com/detail/shorts-avoid-for-youtube/capdpopadgbflaoklceadlimohpcmopm). The public listing reports v0.1.25, checked October 10, 2026. Store installations receive updates automatically.

For manual installation, download `youtube-shorts-avoid-0.1.25.zip` and extract it to a permanent folder. Open `chrome://extensions` or `opera://extensions`, enable Developer mode, select **Load unpacked**, and choose the extracted folder containing `manifest.json`.

For an unpacked update, replace the files in the existing extension folder, reload the extension, and reload YouTube. Use a signed-in account with YouTube set to English. `SHA256SUMS.txt` contains the ZIP checksum.
