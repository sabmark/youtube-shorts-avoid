## Install or update

Download `youtube-shorts-avoid-0.1.16.zip` and extract it to a permanent folder. Open `chrome://extensions` or `opera://extensions`, enable Developer mode, select Load unpacked and choose the extracted folder containing `manifest.json`.

For an update, replace the files in the existing extension folder, reload the extension, and reload open YouTube and Google feedback-history tabs once. Normal feedback removal stays within the popup. Sign-in or account verification may require opening Google history.

The supported interface is English. `SHA256SUMS.txt` contains the ZIP checksum.
