# Shorts Avoid for YouTube v0.1.27

**Both** now sends both feedback actions. In earlier versions, YouTube could move to the next Short right after **Not interested**, so **Don't recommend channel** was never sent. Thanks to the user who reported this.

Changes since v0.1.25:

- Avoid sends **Don't recommend channel** first and **Not interested** last, so both reach the same Short.
- Some Shorts layouts show no notice after feedback. Avoid now also counts an action as confirmed when YouTube's own feedback request succeeds. The extension checks only that request's address and status in the browser's request timing records; it does not read or change the request or response.
- The Avoid and Like buttons match YouTube's own Shorts action buttons: no border, the same background and hover in light and dark themes, 24px icons, YouTube's label font and even spacing.

## Install or update

Install [Shorts Avoid for YouTube from the Chrome Web Store](https://chromewebstore.google.com/detail/shorts-avoid-for-youtube/capdpopadgbflaoklceadlimohpcmopm). Store installations update automatically once the store approves v0.1.27.

For manual installation, download `youtube-shorts-avoid-0.1.27.zip` and extract it to a permanent folder. Open `chrome://extensions` or `opera://extensions`, enable Developer mode, select **Load unpacked**, and choose the extracted folder containing `manifest.json`.

For an unpacked update, replace the files in the existing extension folder, reload the extension, and reload YouTube. Use a signed-in account with YouTube set to English. `SHA256SUMS.txt` contains the ZIP checksum.
