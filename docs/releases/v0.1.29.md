# Shorts Avoid for YouTube v0.1.29

Two fixes for narrow browser windows, where YouTube places the Shorts action buttons on top of the video.

Changes since v0.1.27:

- **Like now moves to the next Short in narrow windows.** YouTube hides its Next button in that layout, so Like used to like the video and then stop. Avoid also uses this when YouTube does not move on by itself after feedback.
- **Avoid and Like match YouTube's buttons on top of the video.** They now use the same white icons and labels on a dark see-through background as YouTube's own buttons, in light and dark themes. Wider windows keep the previous style.

## Install or update

Install [Shorts Avoid for YouTube from the Chrome Web Store](https://chromewebstore.google.com/detail/shorts-avoid-for-youtube/capdpopadgbflaoklceadlimohpcmopm). Store installations update automatically once the store approves v0.1.29.

For manual installation, download `youtube-shorts-avoid-0.1.29.zip` and extract it to a permanent folder. Open `chrome://extensions` or `opera://extensions`, enable Developer mode, select **Load unpacked**, and choose the extracted folder containing `manifest.json`.

For an unpacked update, replace the files in the existing extension folder, reload the extension, and reload YouTube. Use a signed-in account with YouTube set to English. `SHA256SUMS.txt` contains the ZIP checksum.

## Verification

All 123 automated tests passed with zero failures. On November 8, 2026 the new code was run on live YouTube Shorts in signed-in Chrome at 480px and 1920px wide: the buttons matched YouTube's own in both layouts and themes, and Like liked the Short and moved to the next one in both widths.
