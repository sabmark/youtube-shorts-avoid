How to set a shortcut

Select a shortcut field, then press a key or click a mouse button inside it. Add Ctrl, Alt, Shift or Meta if you want. The first click focuses the field.

Tab moves focus. Esc cancels a change. Give each action a different shortcut.

A saved mouse shortcut replaces that button's normal action on Shorts outside editable fields. Browser or mouse software shortcuts may take priority.
